# KerjaTools MVP

Tools gratis untuk pekerja Indonesia.

## Fitur awal
- Kalkulator THR
- Kalkulator kenaikan gaji
- Kalkulator gaji bersih / take-home pay sederhana
- Metadata SEO, sitemap, robots.txt

## Jalankan lokal
```bash
npm install
npm run dev
```

## Catatan THR
Formula kalkulator THR mengacu pada Permenaker No. 6 Tahun 2016, yang masih berstatus berlaku di JDIH Kemnaker pada saat MVP dibuat.
